# 客服对话质量标注工具

一个可本地运行的静态页面工具，用于逐条浏览客服对话并为客服回复打质量标签。

## 功能

- 逐条浏览对话（上一条/下一条）
- 对每条客服回复打质量标签并填写备注
- 自动保存到浏览器本地存储
- 一键导出标注结果（JSON / CSV）

## 部署与运行

无需后端，直接静态部署即可。

### 方式一：本地启动（推荐）

```bash
cd /home/runner/work/-/-
python3 -m http.server 8000
```

浏览器访问：`http://localhost:8000`

### 方式二：直接打开

直接双击或浏览器打开 `/home/runner/work/-/-/index.html` 也可使用。

## 使用说明

1. 打开页面后，默认显示第 1 条对话。
2. 阅读“用户/客服”内容后，选择“质量标签”，可选填备注。
3. 点击“上一条/下一条”继续标注，系统会自动保存当前条目。
4. 标注完成后点击“导出 JSON”或“导出 CSV”下载结果。
